# NrityaVaani Documentation & Research

This directory contains research citations, academic references, and project presentation assets for **NrityaVaani**.

---

## Directory Structure

* **`presentation/`**:
  * `NrityaVaani_Presentation.pptx`: Comprehensive project slide deck detailing system architecture, MediaPipe kinematics, Goonj neural voice synthesis, and real-world impact.
* **`research/`**:
  * `research_references.html`: Interactive catalog of academic papers, Natyashastra treatises, and computer vision literature on human pose estimation in Indian classical dance.
  * `research_references_table.html`: Comparative matrix of dance classification methodologies, accuracy metrics, and datasets.
